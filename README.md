# Видео-фидбэк — плагин Agents Hub

Значок видеокамеры рядом с микрофоном в поле ввода:

1. нажали — браузер спрашивает, какой экран или окно записывать;
2. через 3 секунды идёт запись экрана и голоса, на значке — время; остановить — тот же значок или «Закрыть доступ» в
   полосе браузера (сама кончится через 10 минут);
3. в чат уходит сообщение: что вы говорили, по фразам с временем, и кадры экрана в моменты этих фраз. Сессия выделяет
   из него фидбэк по пунктам.

Видео нигде не пишется — на диск ложатся только эти кадры (как вставленные картинки), не больше 12.

## Сколько это стоит в токенах

Модель не смотрит видео — только картинки. Кадр экрана — около 1,5 тыс. токенов, минута речи текстом — около 400.
Минута записи «кадр в секунду» — около 90 тыс. токенов; здесь — расшифровка и 3–6 кадров, 5–10 тыс.

## Поставить

«Настройки» → «Плагины» → вставить ссылку на этот репозиторий → «Проверить и поставить». Нужны:

- хаб с местом `composer.tools` (кнопка в поле ввода) — дополнение к Plugin API, в общем хабе его пока нет: без него значок не появится;
- модуль «Голос» хаба (`voice.cmd` в hub.json) — тот же, что у микрофона; без него уйдут только кадры;
- Chrome или Edge на компьютере (на телефоне записи экрана нет — значка тоже нет). На macOS браузеру один раз нужно
  разрешение «Запись экрана» в «Конфиденциальность и безопасность».

## Как устроено

Голос пишется кусками, которые режутся в паузах: закончилась фраза — она сразу уходит на распознавание в `/api/voice`,
пока запись идёт дальше. Кадр снимается через 0,4 с после начала фразы и ещё раз, если во время фразы экран сменился и
встал. Часы записи — в отдельном потоке (`tick.js`): вкладку хаба, которая не на виду, браузер притормаживает.

## Тесты

`python3 -m unittest discover -s tests` — манифест и логика (`node --test`), без хаба и браузера.
